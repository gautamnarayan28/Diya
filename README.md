# 🍽️ Dinner Menu

Mobile site that shows what's for dinner tonight, in Hindi and English, with the full 500 kcal recipe from the trainer's plan.

- **आज / Today** — tonight's dish and the week at a glance
- **सभी रेसिपी / All recipes** — all 14 dishes
- **प्लान / Plan** — pick dishes for each weekday and share the link

No install, no server: plain HTML/CSS/JS. Run locally with

```bash
python3 -m http.server 8765
```

See `progress.md` for architecture, status and hand-off notes.
